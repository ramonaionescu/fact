Build the design. Write the script.
1. Design setup. Define dimensions and levels. Each dimension has wording fields shared across its levels, for example emotional state, explanation, and message 1. Enter the appropriate wording for each level. A field can be intentionally empty only when you check Allow empty wording.
2. Master script. Add instruction/text blocks and conversation turns. Put your cursor in a text box and click a field in the sidebar to insert it. The same field can appear repeatedly, and a block can use several dimensions. Placeholder IDs can be renamed from Design setup; references in the current script are updated with them.
3. Build & save. Choose one level per dimension. All its linked wording changes together. Review with or without highlighting, then save as many scenarios as needed. More wording fields do not increase the factorial condition count. Warnings flag dimensions that never appear in the script, but do not establish manipulation validity or realism.
Your browser is your workspace.
This app has no server database, login, analytics, external libraries, or background upload of your scenario content. Separate browsers have separate workspaces. Clearing site data, using private browsing, or changing the website address can remove or separate your workspace. Directly opened local files may not retain storage consistently; use the hosted address and keep backups.
Export project creates a JSON backup with the current setup, master script, saved scenarios, design versions, and unfinished draft. Import project restores it or moves it to another browser. Import replaces the current project; it does not merge projects.
CSV, text, and HTML export all saved scenarios, without colored review highlights. CSV prefixes formula-like strings for spreadsheet safety; JSON, text, and HTML preserve their characters. Exports include researcher metadata such as scenario names; review files before sharing them with participants.
Existing v1 projects open in their original phrase layout. Saved texts stay unchanged. Convert the editable layout on the Master script page to use multiple fields. Version 3 imports version 1 and 2 backups, including their saved scenarios. Older app versions cannot open version 3 backups; keep your original backup before upgrading.
Images renders saved scenarios as transparent PNG or SVG. Select conversation turns, text blocks, or the whole vignette. Optional image-only speaker labels do not change saved scripts. ZIP batches include a researcher-only manifest; only upload the PNGs to participant-facing pages. Preview backgrounds are not exported, and text colors are fixed. Image settings are included in project backups; downloaded images are not stored in browser storage.
The app does not randomly assign participants, check scientific confounds, impose combination constraints, or collect survey responses. Browser storage is not encrypted by this app. Do not use it for confidential participant records.
